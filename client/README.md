# Arquivos do client feitos para este servidor

Arquivos de texto nossos (não são do client original) para copiar por cima dos da pasta do jogo.

- `UI/EffectString.txt`: nomes dos efeitos das skills (o que aparece ao passar o mouse nos ícones do alto da tela),
  em português. A linha n é o efeito n (AffectType da SkillData; 1 Lentidão, 3 Resistência Reduzida da Perseguição,
  13 Assalto...). O do patch 7.57 veio em coreano, e o client mostrava letras embaralhadas. Gravado em Windows-1252
  com CRLF, como os outros textos do client.
